> **I don't code just to code. I code to build things I care about.**

I'm a **Senior Application Developer** who enjoys making complex technology simpler, more reliable, and more useful.

At work, I build and improve cloud-backed applications and APIs. I'm especially interested in **TypeScript, AWS, observability, and automation** understanding how systems behave, diagnosing failures, and removing repetitive work from people's days.

Outside work, I follow my curiosity into **AI experiments, mobile apps, animation, interactive storytelling, and small inventions**. I like learning by making something real, even if it's just a prototype.

## What I work with

- **Backend and cloud:** TypeScript, JavaScript, Node.js, AWS Lambda, API Gateway, CloudWatch
- **Observability:** OpenTelemetry, distributed tracing, AWS X-Ray
- **Apps and interfaces:** React, React Native, HTML, CSS
- **Also exploring:** Python, on-device AI, electronics, robotics, and creative coding

## Selected projects

- 🎨 **[My Village Shikha](https://github.com/Manojhaki/myvillageshikha)** — An interactive illustrated website for an animated story in development, with playful scenery and storytelling.
- 📱 **[rn-local-llm](https://github.com/Manojhaki/rn-local-llm)** — An early-stage React Native experiment in managing small language models on a device. The TypeScript foundation is in progress; it doesn't run inference yet.
- 🧾 **[Receipt Scanner](https://github.com/Manojhaki/recieptScanner)** — A tool that uses AI to extract receipt line items, lets you review them, and exports the result to Google Sheets.
- 🎲 **[Devil's Casino](https://github.com/Manojhaki/Devil-s-Casino)** — A small game exploring probability, risk, and decision-making.

## How I like to build

I like understanding the problem before choosing the technology. Then I break it into smaller pieces, build a working version, and improve it through use and feedback.

I'm always interested in projects where **software, creativity, and real-world usefulness** meet.

When I'm away from the keyboard, you might find me ballroom dancing, drawing characters, or learning how a gadget works.
